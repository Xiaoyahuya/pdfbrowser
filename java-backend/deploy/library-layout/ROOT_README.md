# PDFBrowser 资料库

资料按用途组织。先选择类别，再进入具体技术域或项目；不再通过“教程文档”和数字编号猜测内容位置。

| 类别 | 内容 |
| --- | --- |
| [知识](知识/README.md) | 技术原理、运行时、源码代码课和跨栈方法 |
| [书籍](书籍/README.md) | 原著、技术阅读和读书笔记 |
| [科研](科研/README.md) | 研究方法、集合通信研究和论文笔记 |
| [项目](项目/README.md) | PDFBrowser、ONNX 工具、Linux 实验和 Hybrid AllGather |
| [学习](学习/README.md) | 60 天总计划、专项计划、算法训练和每日任务 |
| [工程](工程/README.md) | 可复用的运维与操作记录 |
| [归档](归档/) | 旧索引、已合并资料和历史版本，只在追溯时使用 |

## 归档规则

- 原理和稳定知识放“知识”，不混入某一天的执行记录。
- 论文、实验假设和研究结论放“科研”；可运行工程放“项目”。
- 长期路线放“学习”，日常操作步骤放“工程”。
- 同一资料只保留一个主位置，旧目录索引统一进入“归档”。
